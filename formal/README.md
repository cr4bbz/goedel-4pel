# Formalization

Gate 7 turns the settled semantic claims from Gates 1–6 into executable regressions and Lean theorems.

The formal layer now has two deliberately different roles:

1. `finite/` is an executable finite-model oracle for named countermodels, exhaustive small searches, and assumption-lattice experiments;
2. `lean/` is the proof layer for general semantic theorems that should not depend on finite enumeration.

The split is intentional. Countermodels are easiest to inspect as concrete finite structures, while general implications and equivalences should eventually be checked independently in Lean.

## Current Gate-7 milestone

### Finite-model oracle

`formal/finite/checker.py` currently encodes:

- the values `T/F/B/N` and involutive FDE negation;
- two-world S5 accessibility;
- actualist existence for finite entities;
- property extensions and four-valued positivity;
- `NEnt+_E` and `NEnt-_E`;
- strong A1;
- `R+`;
- `A2+`;
- `A3-T`;
- `G-sup-v0.1`;
- positive essence and `T2+`;
- `COMP_P^G`, `CONS_G^G`, and `REG_G`.

The first regression suite validates:

- the Gate-6 glut countermodel to `T2+`;
- the Gate-6 gap countermodel to `T2+`;
- the fact that the glut model satisfies `COMP_P^G` but fails `CONS_G^G`;
- the fact that the gap model satisfies `CONS_G^G` but fails `COMP_P^G`;
- schema-level `MC+ <-> MC-` on every valuation of a negation-closed two-world formula family;
- `REG_G => T2+` over the complete small two-world / one-entity `G,Z` search space currently generated by the checker.

The last search retains 204 models satisfying its antecedent and verifies `T2+` in all of them.

Run locally from the repository root:

```bash
python3 -m unittest discover -s formal/finite -p 'test_*.py' -v
python3 formal/finite/checker.py
```

## Lean layer

The Lean package lives under `formal/lean/` and is pinned to Lean 4.30.0 by `lean-toolchain`.

Current modules:

```text
Goedel4PEL/FourValued/Truth.lean
Goedel4PEL/Analysis/Collapse.lean
```

The first Lean theorem proves the Gate-4 collapse-channel equivalence at the correct **schema level**:

```text
MC+ <-> MC-
```

under bilateral negation and involution. This matters because the equivalence is not a pointwise identity for one isolated formula; its proof uses substitution with the negated formula.

Build locally:

```bash
cd formal/lean
lake build
```
