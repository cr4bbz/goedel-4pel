# Gödel–Scott axiom matrix

This file is deliberately a matrix rather than a finished translation. Each classical axiom may admit several inequivalent four-valued liftings.

## Legend

- `CL`: exact classical baseline statement.
- `4V+`: constraint on positive support.
- `4V-`: constraint on negative support.
- `4V±`: combined bilateral constraint.
- `Status`: open / candidate / rejected / proved / countermodelled.

## A1 after Gate 3

Scott's classical A1 is

```text
¬P(φ) <-> P(¬φ)
```

The independent directional components are:

```text
A1-L : -P(φ)  => +P(¬φ)
A1-R : +P(¬φ) => -P(φ)
```

Strong bilateral A1 is `A1-L + A1-R`, equivalently:

```text
v(P(¬φ)) = swap(v(P(φ)))
```

so `T/F` are exchanged while `B/N` are preserved.

## A2 after Gate 5

Rather than choose a four-valued object-language implication, Gate 5 defines semantic necessary positive entailment:

```text
NEnt+_E(φ,ψ,w):
  at every v accessible from w,
  every actually existing +φ-instance is a +ψ-instance
```

The control lifting is:

```text
A2+ : +P(φ) and NEnt+_E(φ,ψ) => +P(ψ)
```

On the `T/F` fragment this recovers the truth-support content of Scott A2.

A negative A2 analogue is not added because it would introduce new structure not required by classical recovery.

## T1 after Gate 5

Mere positive support is too weak for the classical T1 conclusion. Define:

```text
Pos_T(φ) := +P(φ) and not(-P(φ))
```

Then:

```text
A1-R + A2+ => T1-T
T1-T : Pos_T(φ) => +◇∃ᴱx φ(x)
```

The A1 direction used here is `A1-R`, in contrast to the Gate-4 reflection bridge, which uses `A1-L`.

The unrestricted schema

```text
+P(φ) => +◇∃ᴱx φ(x)
```

fails in a one-world S5 model with an empty actual domain and glutty positivity assignments. A positivity glut can absorb the negative support produced by the classical reductio.

## A3 after Gate 5

Two conservative liftings remain relevant:

```text
A3+ : +P(G)
A3-T : Pos_T(G)
```

`A3+` permits `P(G)=B` and does not by itself activate `T1-T`.

The Scott-control branch adopts:

```text
A3-T
```

and therefore derives:

```text
+◇∃ᴱx G(x)
```

from `A3-T + T1-T` without requiring global positivity consistency.

## D1 / Godlikeness after Gate 5

The control definition `G-sup-v0.1` is:

```text
+G(x) iff every +P(φ) is +φ(x)
-G(x) iff some +P(φ) is -φ(x)
```

It immediately yields:

```text
D1+ : +G(x) and +P(φ) => +φ(x)
```

and reduces to Scott D1 on the classical `T/F` fragment.

All four values `T/F/B/N` remain possible for `G(x)`.

## A4 after Gates 3–4

The direct positive-support lifting is:

```text
R+ : +P(φ) => +□P(φ)
```

The informative negative-persistence target is:

```text
R-nec- : -P(φ) => +□¬P(φ)
```

Gate 4 establishes:

```text
without A1:       R+ and R-nec- are independent
strong A1:        R+ <-> R-nec-
```

## Modal collapse after Gate 4

The informative pair is:

```text
MC+ : +χ => +□χ
MC- : -χ => +□¬χ
```

Under involutive FDE negation these are not independent schemas:

```text
MC+ <-> MC-
```

Hence the decomposition target is upstream rather than at collapse itself.

## Gate-4 interface audit after Gate 5

The conditional collapse package was:

```text
A1-L + D1+ + CONS_G + COMP_P + R+ + GW + CONST
```

Gate 5 changes its status as follows:

| Interface | Gate-5 status |
|---|---|
| `D1+` | discharged by `G-sup-v0.1` |
| `CONST` | discharged by full intensional property comprehension / lambda abstraction |
| `GW` | not discharged; only possible Godlikeness is derived |
| `COMP_P` | not implied; strong A1 preserves `N/N` gaps |
| `CONS_G` | not implied by support-based Godlikeness |

Thus reconstructing A2, A3, and D1 does not yet reconstruct modal collapse.
