\section{Formal Correspondence}
\label{sec:correspondence}

Every claim in this manuscript of the form ``Lean proves \(\dots\)'' refers to a
named declaration in the accompanying development. This appendix gives the map.
Lean modules are listed by file stem below
\texttt{formal/lean/Goedel4PEL/}; finite fixtures are listed by function name
below \texttt{formal/finite/}. Both tracks are run in CI, and the Lean package is
pinned to Lean 4.30.0. No declaration below uses \texttt{sorry}, an added axiom,
or \texttt{native\_decide}.

Premise names in the Lean signatures are the definitions of the same name in the
corresponding module; where this manuscript abbreviates a premise list as a
``stack'', the authoritative list is the Lean signature.
